# BIM·AI 건설 시뮬레이터

서울 공동주택 택지 선정부터 용산국제업무지구 매스 배치, 동·층별 일람표, 4D 공정, 5D 예산까지 한 흐름으로 이어지는 시뮬레이션 웹사이트입니다. 화면은 건축 다이어그램 톤(흰 모형·검은 선·점선 지시선·엑소노메트릭)으로 그립니다.

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 0 | `#/` 처음 화면 | 3D 엑소노 히어로, 단계 노드 다이어그램, 단계별 데이터 흐름 매트릭스 |
| 1 | `#/site` 택지 선정 | 서울 후보지 8곳의 세대수·사업성·입지·추진 안정성 비교. 용산을 고르면 2단계로 값을 넘깁니다. |
| 2 | `#/mass` 매스 배치 | 주동 형식 7종(탑상·Y·판상·ㄱ·V·ㄷ자·혼합), 높이 계획, 건축법 시행령 86조③ 인동간격, 동지 일조·한강/남산 조망, 주변 주거 일조 영향 |
| 3 | `#/schedule` 층별 일람표 | 단면 바코드, 층 구성 분해도, 층별 층고·FL·면적·세대·외벽 면적, 지하 굴토량. CSV·JSON 내보내기 |
| 4 | `#/process` 4D 공정 | 작업일 달력으로 블록·동·층 단위 공정 계산, 3D 재생(크레인 포함), 간트 격자, 마일스톤 |
| 5 | `#/budget` 5D 예산 | 물량 × 공종 단가, 공정에 얹은 월별 기성·누계 S커브, 물가상승, 블록×공종 매트릭스, 1단계 개략 공사비 비교 |

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 매스·분석·공정·예산 엔진 검사
npm run build    # dist/ 에 정적 사이트 생성
```

## 배포 (GitHub Pages)

1. 이 폴더를 GitHub 저장소의 `main` 브랜치에 올립니다.
2. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 바꿉니다.
3. `.github/workflows/pages.yml`이 빌드·배포합니다. 주소는 `https://<계정>.github.io/<저장소>/` 입니다.

`vite.config.js`의 `base: './'` 덕분에 어느 하위 경로에서도 동작합니다.

## 구조

```
src/
  main.js            단계 라우터, 머리글 단계 표시, 테마
  store.js           단계 사이 전달값 (브라우저 저장소)
  stage1/            1단계 엔진(후보지 데이터·사업성)과 서울 지도
  yongsan/
    plan.js          대지·블록·주변 맥락(근사) 모델
    massing.js       동 배치, 층고 스택, 피난안전층, 지하 주차, 인동간격 검사
    analysis.js      동지 일조·한강/남산 조망 광선 검사 (순수 함수)
    worker.js        분석을 웹 워커에서 실행
    viewer.js        three.js 3D 뷰어
    context.js       한강·교량·남산·공원·광역 주변 건물(화면용 근사)
    quantities.js    외벽·지붕·굴토 등 예산용 기초 물량
    process.js       4D 공정 엔진 (작업일 달력, 층별 골조 사이클)
    cost.js          5D 예산 엔진 (공종 단가, 월별 기성, 물가상승)
  pipeline.js        2→3→4→5단계 계산 묶음과 공통 서식
  pages/             단계별 화면 (home, site, mass, schedule, process, budget)
```

## 가정과 한계

- 대지는 1,150m × 430m 직사각형으로 단순화했고, 블록 번호는 이 모델의 배치입니다. 존별 면적만 발표 수치에 맞췄습니다.
- 주변 건물은 위치·층수를 근사한 모델입니다. OpenStreetMap 건물 데이터를 연결하면 `plan.js`의 `CONTEXT`를 대체할 수 있습니다.
- 일조 기준: 동지 진태양시 09~15시 연속 2시간 또는 08~16시 합계 4시간 (판례상 수인한도).
