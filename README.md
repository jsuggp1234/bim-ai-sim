# BIM·AI 건설 시뮬레이터

무엇을 지을지(용도 17종)를 먼저 정하고, 전국 후보지 145곳에서 입지를 고르고, 매스를 배치한 뒤 공법·재료 → 4D 공정과 공정 간섭 → 5D 예산 → 위험 예측까지 BIM 모델 하나로 이어지는 시뮬레이션 웹사이트입니다. BIM(물량·형상·공간)과 AI(추천·최적화·확률 예측)가 공정관리·간섭 검토·품질관리·예산관리·위험예측을 함께 수행하는 흐름을 보여 줍니다.

공법을 누르면 그 자리에서 바로 시공 장면이 다시 재생되고, 2D 단면·작업 상세·간섭·이점·공정 단계·현장 조건·결정 기록·전통 대비는 3D 왼쪽 아이콘 메뉴를 눌러 여는 창(2D 단면은 3D 위 작은 창, 크게 보기 가능)으로 봄. 재생은 공종당 150~300초(½×·1×·2×·4×·8× 선택). 고를 때마다 실제 공정 일정대로 시공 장면을 재생하며 그 선택이 만드는 간섭(번호 표식)·문제점·이점, 공기·비용·위험 변화를 함께 보여 줌. 3D는 실사 장면: 하늘과 하늘빛 환경 반사(유리·금속), 해 그림자, ACES 톤 매핑, GPU에서는 앰비언트 오클루전, 재료 질감(유로폼 줄눈·폼타이 구멍이 있는 노출 콘크리트, 흙 알갱이·자갈, 아스팔트 골재, 보도블록, 압연 철재, 합판 거푸집, 쇄석)을 월드 좌표 3방향 투영으로 붙임. 단면으로 자르지 않고 **반투명**으로 속을 보임: 지하 공종은 현장 둘레 흙 덩어리의 앞쪽 절반·지표·흙막이·지하 외벽을 반투명하게(지층 경계선·지하수위 면 표시, 도로·보도 밑 매설물과 인접 건물 지하층까지), 실내 공종은 외장을 유리처럼 비우고, 역타처럼 지하 공사 중 지상 골조가 있으면 지상부를 흐리게. 주변은 **입지의 실제 지도(OpenStreetMap: 반경 1km 건물, 2km 도로·철도·물·녹지·산, 5km 해안선)** 를 대표 동 기준 시뮬레이션 좌표로 옮겨 현장 둘레 가로 모형 바깥을 채우고(지도를 받기 전·끈 경우 같은 택지의 자동 생성 맥락), 같은 매스 배치의 다른 동은 반투명 '계획 동'으로 제자리에 세움. 현장 둘레 가로 모형은 대로(보도블록·연석·차로·횡단보도·신호·버스 정류장·차체 옆모습을 살린 통행 차량·도로 밑 매설물)·이면도로·인접 건물(반사 유리 입면·창틀·블라인드·상가·옥상 설비·지하층)·건너편과 뒤쪽 블록·수관이 울퉁불퉁한 가로수까지 2D·3D 모두 같은 가로 모델. 3D는 **전체 보기**(현장과 지금까지 지어진 건물 전체를 한 화면에, 건물이 오를수록 천천히 물러나고 남은 높이는 윤곽선)와 **작업 부위**(지금 작업하는 곳을 따라감)를 전환. 공법마다 고유 장면을 그림: 흙막이(H-Pile·토류판, 강널말뚝 진동 압입, CIP·SCW 기둥열, D-Wall 1차·2차 패널과 하이드로밀), 지보(버팀보·어스앵커·레이커 소단·역타 슬래브·SPS), 말뚝 항타·현장타설(RCD), 골조(철골 I형강 선행·데크, RC 벽식, PC 조립, 모듈러, 플랜트 모듈 통째 인양 vs 현장 조립 부재 순서·그레이팅), 거푸집(합판·동바리, 알폼, 갱폼 3단 발판, ACS, 슬립폼), 타설 장비(붐 펌프카 도달 거리 경고·고정 배관·버킷·동절기 천막), 크레인 형식, 외장·지붕 재료 무늬. **사람과 장비가 실제로 일함**: 관절이 있는 작업자(안전모·반사 조끼·장갑)가 공종별 동작(철근 결속·망치질·진동기·레이크·흙손 마감·용접 불꽃·볼트 체결·천장 드릴(시저 리프트 위)·도장 롤러·패널 부착·신호봉·측량·호스 잡기 등)으로 일하고, 자재 담당은 적치 자리와 작업 자리를 오가며 철근·합판·배관·덕트·유리를 나름. 인원은 지금 작업 유형의 표준 작업조 규모를 따름. 장비는 대로에서 들어와 게이트로 후진 진입 → 상차·하역 → 진출하는 순환으로 움직임: 굴착은 덤프트럭 3대가 한 대씩 상차 자리에 서고(백호·크람쉘이 흙을 담아 실음, 작업구대 복공판), 타설은 레미콘이 옆 차로로 와서 펌프카 호퍼에 후진해 붙어 붓고 다음 차가 대기, 골조·외장·설비는 자재 트레일러(철근 다발·형강·거푸집·커튼월 유닛·PC 판·덕트 등)가 들어와 크레인이 하역. 장비마다 이름표(예: '덤프트럭 25t · 상차 중'), 3D 위 **지금 작업** 카드에 작업 유형·작업조 인원·투입 장비. **물**: 수면은 물결이 흐르고(세 방향 잔물결), 물가는 얕은 물빛, 바다는 OpenStreetMap 해안선으로 그려 물가에 흰 물거품이 밀려옴(섬은 구멍, 수평선까지). 게이트 세륜기는 세척수가 출렁이고 차가 지날 때 분사, 굴착 바닥 유입수는 흙탕물로. **작업 상세** 창은 지금 단계를 확대 장면(63개 작업 유형)과 투입 장비·작업조·관리 항목·안전으로 보여 줌. 확정 기록표, 전통 공법 대비 효과 |
| 05 | `#/process` 4D·간섭 | 블록·동·층 단위 공정을 3D로 재생. 크레인 반경·인접 굴착·공종 적층·물류 차량·소음 간섭 검출, 모의 담금질로 착공 시차·간격·타설 분할을 최적화 |

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 매스·분석·공정·예산·입지·공법·간섭·위험 엔진·시뮬레이션 장면 검사 (17개 용도 전 과정 포함)
npm run build    # dist/ 에 정적 사이트 생성
```

## 배포 (GitHub Pages)

1. 이 폴더를 GitHub 저장소의 `main` 브랜치에 올립니다.
2. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 바꿉니다.
3. `.github/workflows/pages.yml`이 테스트·빌드·배포합니다. 주소는 `https://<계정>.github.io/<저장소>/` 입니다.

`vite.config.js`의 `base: './'` 덕분에 어느 하위 경로에서도 동작합니다.

## 가정과 한계

- 모든 수치는 공개 자료와 가정에 기반한 시뮬레이션입니다. 실제 인허가·설계·공사비·공기와 다를 수 있습니다.
- 전국 후보지의 항목 점수는 지역 평균 프로필에 부지 성격(산단·도심·항만 등) 보정을 더한 값이며, 근거 자료가 있는 곳은 링크를 붙였습니다.
- 공법 점수(공기·비용·품질·안전·환경)는 일반적인 시공 특성을 0~100으로 옮긴 값에 현장 조건 규칙을 더한 것입니다.
- 세부 공종 판정도 간이 추정식입니다: 소음 90dB(A)@7.5m 거리 감쇠 − 방음벽 감쇠, 정수압 9.81kPa/m, 압송 압력 ≈ 0.045MPa/m × 높이 + 1.5, 창호 열관류율은 지역·주거 여부별 기준값, 급수 정수압 0.0098MPa/m(구역당 약 70m), 스프링클러 헤드 1개당 약 10㎡.
- 04 단계의 간섭 판정은 간이 추정식입니다: 흙막이 변위 δ/H(벽 강성·지보·연약층), 배면 침하 영향 범위 2H, 발파 진동 PPV = 160·(D/√W)^−1.6 (허용 0.3/0.5/1.0cm/s), 항타 소음 105dB(7.5m) 거리 감쇠, 앵커 길이 ≈ 0.6×굴착 깊이 + 8m. 설계 검토를 대신하지 않습니다.
- 위험 발생 확률·영향은 등급(1~5)을 확률과 삼각분포로 바꾼 모델이며, 몬테카를로는 같은 입력이면 같은 결과를 내도록 고정 난수를 씁니다.
- 대지는 택지 면적·장단비·방향으로 만든 직사각형으로 단순화했습니다. 주변 맥락은 방문자 브라우저가 OpenStreetMap에서 받으며, 못 받으면 자동 생성 맥락을 씁니다.
