# BIM·AI 건설 시뮬레이터

서울 공동주택 택지를 고르고(후보지 8곳 또는 직접 입력), 실제 지도 위에 동을 배치해 일조·조망·인동간격을 검토한 뒤 동·층별 일람표, 4D 공정, 5D 예산까지 한 흐름으로 이어지는 시뮬레이션 웹사이트입니다. 고른 택지가 모든 단계의 변수입니다.

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 0 | `#/` 시작 화면 | 가상 도시가 층마다 지어지고 AI가 일조·공정·예산을 계산하는 배경, 시작하기 |
| 1 | `#/site` 택지 선정 | 실제 지도(CARTO 바탕, 못 받으면 자치구 벡터 지도) 위 후보지 8곳, 평가 매트릭스·공급×수익률 산점도 비교, 단순 매스 검토. '프로젝트 시작'으로 고른 택지와 시나리오를 2단계로 넘깁니다. |
| 2 | `#/mass` 매스 배치 | 실사 보기(하늘 환경광·톤 매핑·앰비언트 오클루전·유리 반사)로 시작. 주동 형식 7종(탑상·Y·판상·ㄱ·V·ㄷ자·혼합), 높이 계획, 건축법 시행령 86조③ 인동간격, 동지 일조·수변/산 조망, 주변 주거 일조 영향. 택지 선택·직접 입력, OpenStreetMap 주변 맥락 |
| 3 | `#/schedule` 층별 일람표 | 단면 바코드, 층 구성 분해도, 층별 층고·FL·면적·세대·외벽 면적, 지하 굴토량. CSV·JSON 내보내기 |
| 4 | `#/process` 4D 공정 | 작업일 달력으로 블록·동·층 단위 공정 계산. 가설·흙막이·굴토·기초·지하 골조·지상 골조·설비·창호·내부 마감·준공을 3D로 재생(거푸집·버팀보·크레인·덕트 포함), 단계 탭, 투시 보기, 간트 격자 |
| 5 | `#/budget` 5D 예산 | 물량 × 공종 단가, 공정에 얹은 월별 기성·누계 S커브, 물가상승, 블록×공종 매트릭스, 1단계 개략 공사비 비교 |

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 매스·분석·공정·예산 엔진 검사
npm run build    # dist/ 에 정적 사이트 생성
```

## 배포 (GitHub Pages)

1. 이 폴더를 GitHub 저장소의 `main` 브랜치에 올립니다.
2. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 바꿉니다.
3. `.github/workflows/pages.yml`이 빌드·배포합니다. 주소는 `https://<계정>.github.io/<저장소>/` 입니다.

`vite.config.js`의 `base: './'` 덕분에 어느 하위 경로에서도 동작합니다.

## 구조

```
src/
  main.js            단계 라우터, 머리글 진행 표시(완료·지금·남은 단계), 단계 마침 패널, 테마
  ui/atlas.js        가벼운 웹 메르카토르 지도 (타일 + 벡터 겹 + 핀)
  store.js           단계 사이 전달값 (브라우저 저장소)
  stage1/            1단계 엔진(후보지 데이터·사업성)과 서울 지도
  sim/
    sites.js         택지 설명자 (후보지 8곳 + 직접 입력), 위경도 ↔ 월드 좌표
    plan.js          택지 → 대지·블록·도로·공공시설 배치 틀
    massing.js       동 배치, 층고 스택, 피난안전층, 지하 주차, 인동간격 검사
    analysis.js      동지 일조·수변/산 조망 광선 검사 (순수 함수)
    worker.js        분석을 웹 워커에서 실행
    osm.js           OpenStreetMap(Overpass) 건물·도로·수면·녹지 받기와 해석, 브라우저 저장
    ctxmodel.js      지도가 없을 때의 자동 생성 맥락, 대지 비우기, 지형
    ctxload.js       맥락 고르기(지도 → 저장본 → 자동 생성)와 분석용 주변 상자
    quantities.js    외벽·지붕·굴토 등 예산용 기초 물량
    process.js       4D 공정 엔진 (작업일 달력, 층별 골조 사이클, 세부 단계)
    cost.js          5D 예산 엔진 (공종 단가, 월별 기성, 물가상승)
    viewer.js        three.js 3D 뷰어 (시점, 라벨, 장면 사진)
    scene/           3D 장면: 주변 맥락(context3d), 사업지 BIM(bim3d), 파사드 셰이더, 색, 보이는 방식(look: 하늘·환경광·안개·톤 매핑·오클루전)
  pipeline.js        2→3→4→5단계 계산 묶음과 공통 서식
  pages/             단계별 화면 (intro, site, mass, schedule, process, budget)
```

## 가정과 한계

- 대지는 택지 면적·장단비·방향으로 만든 직사각형으로 단순화했고, 블록 번호는 이 모델의 배치입니다. 용산은 존별 면적을 발표 수치에 맞췄습니다.
- 주변 맥락은 방문자 브라우저가 OpenStreetMap(Overpass)에서 받아 저장합니다. 층수 정보가 없는 건물은 용도·면적으로 층수를 추정하고, 지도를 받지 못하면 택지 성격에 맞춘 자동 생성 맥락을 씁니다.
- 일조 기준: 동지 진태양시 09~15시 연속 2시간 또는 08~16시 합계 4시간 (판례상 수인한도).
